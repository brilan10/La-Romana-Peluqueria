# Credenciales por Defecto del Sistema La Romana

Aquí tienes un listado de las credenciales configuradas por defecto en la base de datos para acceder a los distintos paneles del sistema:

## 👑 Administrador
Acceso total al panel de administración (Dashboard, finanzas, inventario, etc.).
- **Correo / Identificador:** `admin@laromana.cl`
- **Contraseña:** `admin123`

## 👤 Cliente (De prueba)
Acceso al portal de clientes para reservas y compras.
- **Correo / Identificador:** `cliente@email.com` (o también el RUT `12345678-9`)
- **Contraseña:** `123456`

## ✂️ Trabajador / Barbero (De prueba)
Acceso al panel (POS) del trabajador para ver su agenda y marcar citas como completadas.
- **Correo / Identificador:** `carlos@laromana.cl`
- **Contraseña:** `123456`

---
*Nota: Estas credenciales se generan automáticamente al correr los scripts de inicialización de la base de datos (`setup_db.php` y `seed_sim.php`). Se recomienda cambiarlas una vez en producción.*
